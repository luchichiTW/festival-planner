# megaport2026 更新紀錄

每個版本對應一個 git tag `megaport2026@<版本>`。

## 1.0.0

- 從原本的「大港撞團」（`luchichiTW/megaport2026`）搬到共用引擎，網址 https://chiparashi.tw/megaport2026/ 。
- 121 場演出、62 份官方介紹、試聽（Spotify、Apple Music、YouTube、Podcast、街聲）、場地地圖與官方時間表圖、中英文介面、巧虎彩蛋。
- 新功能（來自浪人祭的引擎）：撞團分組與備選、備份連結、搜尋相近名字、活動當天的下一團、可離線的 PWA 與自動更新。
- 地圖點舞台會列出接下來的演出，可以直接跳到時間表上那一團。
- `artifact/index.html` 是由 `build.mjs` 產生的單檔版本（含中文地圖與時間表圖，不含試聽）。
