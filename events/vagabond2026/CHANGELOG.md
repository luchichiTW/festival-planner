# vagabond2026 更新紀錄

每個版本對應一個 git tag `vagabond2026@<版本>`。

## 1.7.3

- 加主畫面卡片拿掉「官方網站」「GitHub 原始碼」兩個按鈕，只留步驟和 👌。

## 1.7.2

- 手機橫放時，上方的標題列（浪人祭、日期地點、EN、深淺色）先藏起來，時間表從最上面開始，能看的時段更多；轉回直的就回來。

## 1.7.1

- 拿掉換新版本後跳出的「已更新到 MM/DD 的時間表」提示（會蓋住加主畫面卡片的 👌）。版本和時間表日期在「關於」裡看得到。

## 1.7.0

- 標題：「2026」從「浪人祭」旁邊移到右邊的文字，分兩行：日期在上、地點在下。
- 還沒加到主畫面時，手機上每天最多提醒 3 次（打開頁面，或離開半小時後回來），加到主畫面後就不再出現。
- iPhone 的 Safari：提醒卡片附上加入主畫面的 5 個步驟實機截圖（iOS 26），用黃色太陽框和手指標出要按的地方；左右滑或點圖片換下一步。

## 1.6.0

- 英文介面：右上角可以切換 EN／中。舞台、演出名稱、浪人塾講座標題都用官方英文版時間表的字；場地沒有官方英文，維持中文；藝人介紹只有中文。
- 很窄的手機上，底部分頁的字太長時改成兩行，不會擠到隔壁。
- 一律先顯示中文；按「EN」才換英文，選過會記住（不再依瀏覽器語言自動切換，搜尋引擎看到的也是中文頁）。
- 第一次使用改成大港撞團那套：畫面中間的卡片，長按看表演者資訊（以 C.Holly 為例）、團序與地圖、先加主畫面再排團。
- 隱私說明在 App 裡用面板打開，不會跳到別的頁面；面板都可以往下拉關閉。
- 地圖按鈕先放「官方還沒公布場地圖」的說明，附官網場地資訊連結；官方公布後換成真的地圖。
- C.Holly 加上試聽：〈三不娶〉官方 MV（YouTube）。
- 導覽裡的 C.Holly 卡片可以直接試聽：點「點一下試聽」才載入 YouTube 播放器，隱私說明、常見問題跟著改寫。
- 淺色模式的「浪人祭」字標改成雙色：紅字配金黃影（深色版的金字紅影反過來）。

## 1.5.4

- 「關於」打開時從最上面開始，不會直接捲到最下面的「完成」。抽籤、導覽等面板也一樣不再自己捲動。

## 1.5.3

- 描述精簡：標題、頁面描述、分享預覽圖、頁尾都不再寫「非官方」，保留資料來源和「演出異動以主辦方現場公告為準」。

## 1.5.2

- 文字修正：個資一律寫「蒐集」（不蒐集個資），關於、常見問題、頁面描述與結構化資料都一起改。

## 1.5.1

- 換新的圖示：紅磚圓窗裡的夕陽、光芒和海浪，奶油色底，不再用「浪」字。首頁的票券也一起換。
- 已經加到主畫面的人，要把舊圖示刪掉、再加入一次，才會換成新圖示；團序不受影響。

## 1.5.0

- 第一次打開有三步導覽：怎麼排團（點一下加入、長按看介紹與試聽、變淡是撞團）、我的團序（撞團抽籤、換手機用備份連結）、加到主畫面且沒網路也能開。取代原本時間表上的一行提示和只在 iPhone 出現的「先加入主畫面」。
- 加到主畫面這一步依裝置說怎麼做：iPhone 用「分享」→「加入主畫面」；Android 和電腦的 Chrome、Edge 直接有「安裝」按鈕；IG、LINE、FB 的內建瀏覽器提醒先用 Safari 或 Chrome 打開，並可複製網址。從主畫面打開時不出現這一步。
- 已經在用的人只會看到「加到主畫面」這一步，而且只出現一次。

## 1.4.2

- 時間表滑到底不再放文字。「特色」和「常見問題」移到「關於」裡；「我的團序」最下方「關於・自己做一個」旁邊多一個「隱私說明」。
- 「關於」拿掉「外觀」：深淺色只用右上角的按鈕切換；切回跟系統一樣的顏色，就恢復跟隨系統。

## 1.4.1

- 時間表滑到底有「特色」和「常見問題」：離線可用、不用註冊、不收集個資，團序存在哪裡、換手機怎麼搬；連到新的隱私說明頁（https://chiparashi.tw/privacy/）。
- 換新版更穩：剛打開時，等頁面載入完才換上新版，不會因為瀏覽器同時抓圖示而晚 30 秒才換。

## 1.4.0

- 長按卡片可以試聽：Spotify、Apple Music、YouTube 各放一首代表曲，同一組藝人每個平台不同首（58 組、112 首，理由與來源在 `data/artists.json` 的 `picks`）。打開卡片才載入，離線不顯示。
- 每位有資料的藝人一頁：`artists/<slug>/`，有演出時間、介紹、推薦曲目與平台連結；按「在時間表上看」會打開工具並捲到那一團。
- 「用 Claude 做你自己的」頁：`claude/`，中英並列，有可複製的提示、單檔與資料 JSON 的網址。
- 時間表最下方加一行資料日期與「非官方」。分享連結時有預覽圖。
- 不執行 JavaScript 也讀得到：工具頁裡有文字版時間表，每頁都有 Markdown 版，另有 `sitemap.xml`。
- 改用新的共用引擎（大港搬過來時一起做的）。畫面與團序不變。
- 5 位藝人的 YouTube 連結改成放 MV 的官方頻道（ano、紫今、理想混蛋、Laura day romance、JABBERLOOP）。

## 1.0.1

- 內容與 1.0.0 相同，只換版本號，用來確認已安裝的 App 會自動換上新版、團序不變（驗收 AC-07）。

## 1.0.0

- 網站版上線：https://chiparashi.tw/vagabond2026/ ，可加入主畫面、離線使用，新版本會在切到背景或下次打開時自動換上。
- 時間表與藝人資料取自原本的浪人祭 artifact（資料日期 2026/10/17）：74 場演出、73 份簡介、112 個平台連結。
- 每場演出改用固定代碼 ID；artifact 的備份連結（`#p1-…`）在網站上可以直接還原，也能在「我的團序」貼上。
- 字型改成放在網站上的子集（Chiron GoRound TC、Chivo Mono），載入時不連到任何第三方。
- 新增「關於・自己做一個」：連到這個活動的原始碼、CLAUDE.md 與原始 artifact。
- `artifact/index.html` 是 2026/10/17 時間表版本的 artifact 原始檔。
